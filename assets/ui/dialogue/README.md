# Ninja Adventure dialogue assets

Unmodified PNGs from **Ninja Adventure - Asset Pack.zip**, downloaded from the author's itch.io
page (upload 16981275, dated 29 March 2026), under `Ninja Adventure - Asset Pack/Ui/Dialog/`:
https://pixel-boy.itch.io/ninja-adventure-asset-pack

- speech.png: Ui/Dialog/DialogueBoxSimple.png (316 × 60)
- portrait.png: Ui/Dialog/FacesetBox.png (48 × 48)
- reply.png: Ui/Dialog/ChoiceBox.png (64 × 20)

License: ../../LICENSE_NinjaAdventure.txt (Pixel-boy and AAA, CC0). The source bytes are
preserved. VillagePanel uses nine-slice margins to retain the borders at variable UI sizes.
The simple dialogue box supports the separate portrait and name row; the precomposed
DialogBoxFaceset alternative is not used. These replace the generic theme/nine_path frames
previously copied from the separate Godot example project.
