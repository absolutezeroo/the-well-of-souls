# 0011: Help without judgement

**Status**: accepted, 2026-10-28 (decided by Claude on the owner's delegation).

**Context**: the Game Accessibility Guidelines' basic level asks for a wide choice of difficulty
and a way to change it during play; Hades' God Mode and Celeste's Assist Mode do it without
judging the player.

**Decision**:
- An **assist option** in the settings, offered plainly (never mocked): the hero takes 20 % less
  damage, 2 % more after each death with it on, up to 80 %. Runs with it on are not sent to the
  online leaderboards and don't set records; everything else (souls, story, achievements) counts.
- From the pause menu, the difficulty of the current run can be **lowered**; the run then leaves
  the leaderboards and records like an assisted run.
- The charged attack has an alternative to holding: a "tap to charge, tap to release" option.

**Consequences**: the run save records "assisted"; leaderboard submission checks it.
