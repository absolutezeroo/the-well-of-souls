# 0002: One world pack, one UI skin

**Status**: accepted, 2026-10-27.

**Context**: an agent imported a Craftpix white-marble temple: another palette, projection,
outline and detail density, and a licence forbidding redistribution of the files. It clashed
with the whole village and was replaced by the pack's own shrine house.

**Decision**: world art comes from Ninja Adventure (CC0) or is drawn on its colours; the window
skin is Kenney's (CC0). Another source needs a new decision.

**Consequences**: look in the pack first (docs/art-bible.md "Sources"); never import another
pack. Checked: `tools/design/check.py` (provenance in REUSE.toml, world palette).
